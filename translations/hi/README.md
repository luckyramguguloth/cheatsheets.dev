## ✨ यह रिपोजिटरी क्यों?

- 🔌 **100% ऑफ़लाइन कार्य करता है** — एक बार क्लोन करें, हमेशा खोजें। इंटरनेट की कभी आवश्यकता नहीं।
- 🚫 **कोई विज्ञापन नहीं, कोई ट्रैकिंग नहीं, कोई पेवॉल नहीं** — वास्तविक, सत्यापित कमांड्स; बिना किसी भ्रामक या नकली सामग्री के।
- 🌍 **सभी के लिए उपयुक्त** — सॉफ्टवेयर डेवलपर्स, डेवऑप्स इंजीनियर, एआई/एमएल शोधकर्ता, सिस्टम आर्किटेक्ट्स, आईटी सपोर्ट तकनीशियन, पीसी बिल्डर्स और गेमर्स।
- 🛡️ **डिजास्टर और क्रैश रिकवरी रनबुक्स** — प्रोडक्शन आउटेज, कर्नेल पैनिक, आउट-ऑफ-मेमोरी (OOM), रैनसमवेयर, बूट लूप और नेटवर्क विफलता से निपटने के संपूर्ण चरण।

## ⚡ त्वरित शुरुआत

```bash
# रिपोजिटरी क्लोन करें
git clone https://github.com/yourusername/cheatsheets.dev
cd cheatsheets.dev/version2

# खोज स्क्रिप्ट को निष्पादन योग्य बनाएं (Linux/macOS)
chmod +x search.sh

# सभी 74 चीटशीट्स में कोई भी कमांड तुरंत खोजें
./search.sh "cuda oom"
```

> **बुनियादी खोज के लिए किसी बाहरी टूल की आवश्यकता नहीं है।** [fzf](https://github.com/junegunn/fzf) वैकल्पिक है परंतु इंटरएक्टिव फ़ज़ी खोज को सक्षम करता है।

## 🖥️ इंटरएक्टिव वेब ऐप (लोकलहोस्ट डॉक्स)

त्वरित, उत्तरदायी और समृद्ध ग्राफिकल अनुभव के साथ चीटशीट्स को पढ़ने और खोजने के लिए अंतर्निहित लोकल डॉक्स ऐप शुरू करें:

```bash
# version2 डायरेक्टरी में एक स्थानीय वेब सर्वर शुरू करें
python -m http.server 8000
```

फिर अपने ब्राउज़र में निम्न यूआरएल खोलें:
👉 **`http://localhost:8000/docs/`**

**लोकलहोस्ट व्यू की प्रमुख विशेषताएं:**
- 🔍 **तत्काल लाइव खोज:** विज़ुअल हाइलाइट्स (`<mark>`) के साथ रीयल-टाइम मल्टी-कीवर्ड फ़िल्टरिंग।
- 🗂️ **7 श्रेणी फ़िल्टर टैब:** All (74), Dev (30), DevOps (10), Gaming (5), Hardware (5), AI & ML (8), Systems (8), और IT Support (8) के बीच तुरंत स्विच करें।
- 🔮 **ग्लासमॉर्फिक रीडर मोडल:** पेज को रीलोड किए बिना मार्कडाउन शीट्स को तुरंत पढ़ें।
- 📋 **सिंगल-क्लिक कोड कॉपी:** किसी भी कमांड या कॉन्फ़िगरेशन स्निपेट को कॉपी करने के लिए समर्पित बटन।
- 📴 **100% ऑफ़लाइन सुरक्षित:** शून्य बाहरी निर्भरता या रिमोट सीडीएन की आवश्यकता।
